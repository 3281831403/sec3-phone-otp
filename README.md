短信验证码接口被脚本刷了几万条，验证码没变过，谁拿到都能用同一个码登录：现在需要把发送、校验和批量处理都收回到服务端契约内。每次发送都必须用不可预测的随机值重新生成验证码，同一手机号的发送要受时间窗口和次数约束，校验失败累计达到上限后必须停止继续尝试。验证码只能成功使用一次，有效期由服务端时间和签发记录判定，过期、已用、错误都要拒绝。发送接口对已注册和未注册手机号必须返回完全一致的响应，不得让人从响应判断号码状态。批量请求中的每一项都要使用自己的手机号和验证码独立完成校验，不得共享或沿用前一项的验证码。不变量是同一验证码只能成功一次，超过发送频率或失败次数上限必须拒绝。
